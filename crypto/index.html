가입 방법 (3분 컷)

아래 4단계만 따라 하면 평생 수수료 할인이 자동 적용됩니다.

  1. 1

    레퍼럴 링크 클릭

    위 카드에서 Bitget 또는 BingX의 '가입하고 혜택 받기' 버튼을 누르세요. 코드가 자동으로 입력된 상태로 가입 페이지가 열립니다.

  2. 2

    이메일·비밀번호 입력

    이메일(또는 휴대폰)과 비밀번호를 입력합니다. 레퍼럴 코드란이 비어 있으면 위에서 복사한 코드를 직접 붙여 넣어주세요.

  3. 3

    KYC 인증 (신분증)

    신분증과 얼굴 인증으로 KYC를 완료합니다. 보통 5~10분 내 승인되며, 입출금·고액 거래에 필수입니다.

  4. 4

    입금 후 거래 시작

    업비트·바이낸스 등에서 USDT를 입금하면 바로 거래 가능합니다. 가입 보너스는 미션 완료 시 자동 지급됩니다.

⚠ 꼭 확인하세요

이미 다른 코드로 가입한 계정에는 본 혜택이 소급 적용되지 않습니다. 신규 이메일로 가입하거나, 기존 계정 삭제 후 재가입이 필요합니다.

자주 묻는 질문

레퍼럴 코드를 사용하면 정말 수수료가 할인되나요? ▾

네. 본 페이지 코드는 거래소 공식 파트너 코드로, 가입 즉시 평생 할인율이 계정에 적용됩니다. 별도 신청 절차는 없습니다.

이미 가입한 계정도 혜택을 받을 수 있나요? ▾

레퍼럴 혜택은 신규 가입 시에만 적용됩니다. 기존 계정에는 소급 적용이 불가하므로, 신규 이메일로 재가입하시거나 거래소 고객센터에 계정 삭제를 요청한 뒤 재가입해야 합니다.

KYC를 꼭 해야 하나요? ▾

입출금과 일정 금액 이상 거래에는 KYC가 필수입니다. 보안 강화와 보너스 수령 조건이기도 하므로, 가입 직후 완료하는 것을 권장합니다.

페이백은 언제 어떻게 받나요? ▾

거래 시 발생한 수수료의 일부가 자동 할인되어 정산됩니다. 추가 페이백은 거래소 정책에 따라 매월 또는 매주 USDT로 지급되며, 가입 후 안내 받으실 수 있습니다.

국내 거래소(업비트·빗썸)와 어떤 차이가 있나요? ▾

해외 거래소는 선물·레버리지 거래, 코인 종류, 수수료 측면에서 유리합니다. 단 본인 책임 하에 투자해야 하며, 세금·자금 송금 규정을 반드시 확인하세요.
