# MindFlow — 마인드맵 & 메모

XMind 스타일의 마인드맵 + 메모 웹앱. 서버 없이 HTML 파일 하나로 동작하는 정적 사이트입니다.

🔗 **라이브 사이트:** https://yeodongwon519.github.io/-/

---

## 파일 구성

| 파일 | 설명 |
|------|------|
| `index.html` | **MindFlow 마인드맵 앱 본체** (HTML+CSS+JS 한 파일에 모두 포함) |
| `.nojekyll` | GitHub Pages가 파일을 그대로 서빙하도록 하는 설정 |
| `saju.html` / `saju.js` / `styles.css` | 이전에 만든 사주 풀이 사이트 (별개) |

마인드맵만 보려면 `index.html` 하나만 있으면 됩니다.

## 로컬에서 실행하기

별도 빌드/설치 없음. 둘 중 아무거나:

- `index.html` 을 브라우저로 더블클릭해서 열기
- 또는 간단한 로컬 서버:
  ```bash
  python3 -m http.server 8000
  # 브라우저에서 http://localhost:8000 접속
  ```

## 주요 기능

- 자동 정렬 트리형 마인드맵 (좌우 균형 배치)
- 키보드: `Tab` 하위 · `Enter` 형제 · `Del` 삭제 · `F2`/더블클릭 편집 · `Space` 접기
- 노드별 메모(📝), 색상 태그, 접기/펼치기
- 여러 맵 관리(🗂) — 폴더 이름은 중심 주제 글자를 자동으로 따라감
- 팬/줌, 화면 맞춤, 다크/라이트 테마
- 내보내기: PNG · SVG · JSON / JSON 불러오기
- 실행취소/다시실행

## 데이터 저장 방식

만든 마인드맵·메모는 **브라우저 localStorage**에만 저장됩니다.
- 코드(이 저장소)와는 별개 — GitHub에 올라가지 않음
- 기기/브라우저마다 따로 저장됨 (자동 동기화 ❌)
- 중요한 맵은 앱의 **⬇ 내보내기 → JSON** 으로 백업 권장
